## 🚀 Getting Started

### **Prerequisites**
- Node.js (v16 or higher)
- npm or yarn package manager
- Git for version control

### **Installation**

1. **Clone the repository**
```bash
git clone https://github.com/ghassan-emran/portfolio.git
cd portfolio
```

2. **Install dependencies**
```bash
npm install
# or
yarn install
```

3. **Start development server**
```bash
npm run dev
# or
yarn dev
```

4. **Open in browser**
Navigate to `http://localhost:5173` to view the portfolio

### **Available Scripts**

```bash
# Development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview

# Lint code
npm run lint
```

## 🎨 Customization

### **Color Scheme Customization**
The portfolio uses a carefully crafted dark theme with emerald accents. To customize colors, update the Tailwind configuration:

```javascript
// tailwind.config.js
module.exports = {
  theme: {
    extend: {
      colors: {
        primary: '#10B981',      // Emerald green
        secondary: '#1F2937',    // Dark gray
        accent: '#374151',       // Medium gray
      }
    }
  }
}
```

### **Content Customization**
1. **Personal Information**: Update Hero.jsx with your details
2. **About Section**: Modify About.jsx with your story and skills
3. **Projects**: Update Projects.jsx with your project portfolio
4. **Experience**: Customize Experience.jsx with your work history
5. **Contact**: Update Contact.jsx with your contact information

### **Adding New Projects**
```javascript
// In Projects.jsx, add to the projects array:
{
  title: 'Your Project Name',
  description: 'Project description...',
  image: 'project-image.png',
  technologies: ['React', 'Node.js', 'MongoDB'],
  category: 'fullstack',
  github: 'https://github.com/username/repo',
  live: 'https://your-project.com',
  featured: true
}
```

## 🌐 Deployment

### **Vercel Deployment (Recommended)**

2. Set build command: `npm run build`
3. Set publish directory: `dist`
